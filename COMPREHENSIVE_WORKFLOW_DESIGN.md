# Comprehensive Onboarding Workflow Design
## 3 Account Types: Individual, Couple Shared, Couple Shell

---

## ACCOUNT TYPE SELECTION (Step 0)

**Question**: "How would you like to create your account?"

**Options**:
1. **Individual Account** 
   - Single user, single login
   - "I'm creating a profile for myself"

2. **Couple Shared Account** 
   - One profile, two separate login emails
   - Both partners can log in and manage the profile
   - "We want one shared profile that we both can access"

3. **Couple Shell Account**
   - Two individual profiles that link together
   - Each partner maintains their own profile
   - Creates a combined "couple view"
   - "We want our own individual profiles that connect together"

## SUMMARY OF KEY DIFFERENCES

### Individual Account
- One person, one login
- Complete control
- 18 steps
- Full individual profile

### Couple Shared Account
- One profile, TWO separate login emails
- Both can log in with their own email/password
- Shared management (changes by one partner seen by other)
- 19 steps
- Combined couple profile from the start
- Both partners answer questions

### Couple Shell Account
- TWO individual profiles that link together
- Each partner has complete individual account
- Link creates a "couple shell" view
- Can be contacted individually OR as couple
- 20 steps (18 individual + 2 linking steps)
- Full independence maintained
- Either can unlink without affecting individual profiles
