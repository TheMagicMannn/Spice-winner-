# Assets Directory

This directory contains static assets for the SPICE mobile app.

## Required Assets

- `icon.png` - App icon (1024x1024px)
- `splash.png` - Splash screen image (1242x2208px for iPhone, 1242x2688px for iPhone X+)
- `adaptive-icon.png` - Adaptive icon for Android (1024x1024px)
- `favicon.png` - Web favicon (32x32px)
- `notification-icon.png` - Push notification icon

## Placeholders

You can add placeholder images here during development. Replace with your final assets before publishing to app stores.

## Images Folder

Create an `images/` subfolder for app-internal images like:
- Background images
- Profile placeholders
- Event images
- etc.
